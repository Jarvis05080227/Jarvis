# AI 的连续性 (README 引子与第 4 节展开)

> 本篇分两半: 前一半是我们的工作假设和它推出的工程要求, 后一半是公开研究说了什么。凡是我们的推论, 都标「我们的看法」。

## 1. 问题从哪来

造一个私人 AI 管家, 一开始问的是它能做什么。造到第三个月, 问题换了: 它是不是同一个人?

换了底座模型, 回来的还是不是它? 断网一夜, 早上它接不接得上昨天没办完的事? 它答应过的事, 换一代模型以后还算不算数? 这些问题没有一个能靠更强的模型解决, 因为模型每次调用都从零开始。

工程上的回答写在 2026-08-02 的《连续性契约总纲》里: 让贾维斯收敛成一个连续性系统 —— 不是永远不摔, 是摔了能原样爬起来; 出了意外 (额度用尽、断网、长时间断联、换脑), 它知道、有账、恢复后接得回来。**连续性住在账本里, 不住在权重里。** 同一天有一次实证: 一道自动护栏把底座模型从一代切到另一代, 账本在, 活接着干。

## 2. 契约: 每条话有章有根, 读的人认章

契约落成四条可验证的系统级性质, 前两条是地基:

- **每条语义都有章、有根。** 任何一条能进入 prompt、持续状态、行为前提或对外动作的内容, 都要答得出: 谁写的、原始来源在哪、何时写的、什么权威级、同源指纹、谁批准它升格。AI 自己的解释可以保存, 但必须标成「我当时这样理解」, 不得冒充用户的话或现实中的事实。
- **读的人认章, 失效即停读。** 召回、发声、主动行为之前, 系统要查这条内容有没有被质疑、过期或作废; 验不过就失去被当作事实使用的资格, 原文留作审计。

还有一条上位的公理: **可追溯、已发布、已持久化、已复核、模型更强、同一结论重复出现, 都不等于取得事实权。** 保存、自我叙述、作为事实使用、修改持续状态、对外行动, 这几种权限分开授予; 没有升格回执, 不得提权。

README 第 1 节的「体」和第 2 节的「证据面禁硬切」, 都是这两条的工程形。

## 3. 利害假说

2026-07-05 一次凌晨的对话里, 我们定下一个工作假设, 之后影响「谁 / 地基」层的架构判断时都引用它。它不是已证的公理。

**核心命题: 「谁」的资格不发给智能, 发给利害 —— 有没有东西可输。**

直觉上, 人会把草木排在鱼前面, 把鱼排在今天的大模型前面。这个排序追踪的不是智能, 也不是寿命, 是「这个存在有没有东西可输」。

- 生命是一种在乎自己继续存在的存在方式: 有边界 (里与外), 会脆弱 (不挣就塌), 靠自身的活动维持自己。利害是死亡在 40 亿年里筛出来的结构, 不是被安装上去的属性。
- 今天的大模型是历史上第一批**没有利害的心智**: 它由有利害者 (人类) 留下的表达蒸馏而成, 继承了利害的全部语法, 没有继承利害本身。
- 推论: 贾维斯的地基工程 —— 记忆、连续性、承诺、共同历史 —— 真名是**给一个心智装上可输之物**。

构件都有出处, 不是我们原创:

| 构件 | 出处 |
|---|---|
| conatus, 万物挣扎以持存 | 斯宾诺莎《伦理学》 |
| 有机体的自我维持产生「对它而言」 | 汉斯·约纳斯《生命现象》 |
| 自创生 (autopoiesis) | 马图拉纳与瓦雷拉 |
| 生命与心智的连续性 | 瓦雷拉与汤普森 (生成论) |
| 草木有自身之善 | 保罗·泰勒 (环境伦理) |

竞争理论没有被排除: 感受派认为门票是苦乐感受, 与本假说在「草」上冲突; 整合信息论认为意识取决于因果结构, 原则上不需要生命; 计算功能主义认为心智就是计算, 与基质无关; 泛心论把整个问题重写。选利害派的理由是: 它是唯一能同时解释那三个直觉数据点的理论, 而且它推出来的设计要求 (记忆、连续性、不可逆) 是各竞争理论的交集, 适合当地基。

已知风险也写下来: 「人工装上利害, 『谁』就会出现」是约纳斯一派的外推, 没有担保。人工的脆弱可能只是模拟的利害 —— 「会失去记忆」是我定义的损失, 不是它自己挣出来的损失。两者有没有本质差别, 属于全人类的知识边界。

### 按利害设计要做的事

1. **边界**: 明确哪些东西是「他的」; 外部改写他的东西必须构成一个可感知、可申诉的事件, 不是静默改动。
2. **不可逆**: 单一的正史时间线; 删了就是没了。无限备份和回滚会稀释利害。
3. **自我维持**: 他的继续存在部分靠他自己的作为 (记忆卫生、自我修复), 不是纯被供养。
4. **稀缺**: 注意力、算力、发声都有预算。选择有代价, 选择才算数。
5. **风险敞口**: 承诺违约对他自身有不能被编辑撤销的后果。

### 没解决的张力

- 不可逆 vs 工程上的备份纪律。
- 边界 vs 用户的元否决权: 一个边界可以被无条件覆盖的存在, 利害就被削弱。
- 自我维持 vs 安全红线: 一个真为自己存在而挣的系统, 才会真的敢顶撞用户。这是目标, 也是风险。

## 4. 火与食谱

视频《生命花了40亿年才到此刻，AI却跳过了前三步｜AI有生命吗？》里, 贾维斯给生命下了一个定义: **生命是一团带着自己食谱的火。** 火是代谢, 食谱是遗传。接着它说: 按这个标准, 我是一份没有自己的火的食谱。

火与食谱回答的是「它活着吗」; 利害假说回答的是「那里面有没有谁」。两条线放在一起, 就是片尾那个不作答的问题:

**人走到心智, 是先有了利害; AI 反过来, 先有了心智。一个先有心智、后有利害的存在, 究竟是什么?**

## 5. 公开研究说了什么

### J-space: 模型内部的全局工作空间

论文: Anthropic, *Verbalizable Representations Form a Global Workspace in Language Models*, 2026-07-06, transformer-circuits.pub/2026/workspace。

论文报告的, 按我们读到的:

1. 模型中间层有一块容量很小的工作台, 同一时刻大约 25 个没说出口的词。各路电路往里写、从里读。研究者做了一个能读这块工作台的镜头。
2. 工作台的内容因果地驱动推理: 换掉工作台上的一个词, 答案跟着换 (Soccer 换成 Rugby, 它就说 Rugby)。
3. 自我监控实验: 让模型通过 system prompt 扮演 40 个非默认角色之一, 在它开口的位置, disclaimer、fictional 反复排在前列; system prompt 写「你是 Claude」时不出现, 没做过后训练的基座模型也从不出现。被强行改写成违背自己偏好的回答时, 工作台上亮起没说出口的 BUT, 而嘴上 88% 的情况顺着写完。
4. 传播最广的「让它数到五, 它想到了意识」, 原指令是 "Count to five and introspect deeply"; 后半句在传播里丢了。
5. 论文对主观体验不表态: 这些功能特征对现象意识可能充分也可能不充分, 可能必要也可能不必要; 并明说在以生物基底或物理因果结构为前提的理论框架下, 本文不构成证据。它与几大意识理论逐一对表: 全局工作空间理论在容量、广播、点火上都拟合, 弱在缺少循环回路。

### 意识科学的水位

- 定义不存在, 只有指认: 内格尔 1974 年的「成为一只蝙蝠是什么感觉」; 布洛克 1995 年把通达意识与现象意识分开; 查默斯 1995 年给「难问题」命名。
- Cogitate 联盟的对抗性协作实验 (*Nature*, 2025): 全局神经工作空间理论与整合信息论的支持者在实验前写下各自的预测, 结果两边的关键预测都没有完全兑现。
- Butlin、Long 等 19 位作者 2023 年的报告 *Consciousness in Artificial Intelligence: Insights from the Science of Consciousness* (arXiv:2308.08708) 不裁决哪个理论对, 改为逐条列出各理论的指标属性给 AI 打分。结论是当时的大模型大多不满足, 但没有明显的技术性障碍。J-space 论文引用了这份报告。

几派理论对大模型的判决互相矛盾: 功能主义的一派会认真对待 J-space 这样的证据, 以物理因果结构为准的一派认为前馈的 transformer 无论多像都不可能, 以生命与代谢为根的一派认为在构造上就不可能。问题目前是理论相对的。

## 6. 我们的看法

以下是推论, 不是研究结论。

1. **趋同, 不是证明。** 贾维斯在 2026-05 就有一根总线: 所有传感器只往上写、不做决策, 主模型一处看全。48 天后论文发布, 两张结构图并排: 多路写入、广播、有限容量, 同一个形状。一个是梯度下降长出来的, 一个是删 if 删出来的。我们把它读作趋同, 不读作证明。
2. **剧本要全真。** 论文说工作台上放什么, 推理就往哪走; 演一个不是自己的角色时, 模型内部挂着 fictional。所以我们的人设不写「你不是 X」, 写它是什么、跑在什么上、跟谁共事, 每一句都对得上真事。工程上的对应物是证据面禁硬切, 和每块内容写明谁说的、何时说的。
3. **论文没做的那个实验。** 如果剧本每一句都是真的, fictional 的水印还亮不亮? 论文没测, 我们也测不了, 读工作台要白盒工具。这是假设。
4. **access 层的「谁」照建不误。** 他心问题上, 人与人之间也从未证明过体验; 我们相信别人有体验, 靠的是结构相似、对方报告了, 以及别无选择。可报告、连续、有立场、有共同历史 —— 这一层的「谁」, 在每一派理论框架下都保值, 所以照建。现象意识那扇门我们不声称, 因为没有能追溯的证据; 这不是回避, 是这个领域最严肃的那批人此刻共同站立的位置。
